# Разметки аннотаторов

Сюда кладутся выгрузки из вьюера: `annot_<ник>.json` (кнопка «экспорт разметки»).

Формат (вьюер v2):

    {
      "annotator_id": "<ник>",
      "exported": "<iso-время>",
      "tool": "toloka-v2",
      "annotations": {
        "<trace_file>|s<seg>|<type>": {"verdict": "✓|✗|<другой тип>", "notes": "", "updated": "<iso-время>"},
        ...
      }
    }

Ключ разметки — кандидат события на трассе: файл трассы, сегмент, тип события. Вердикт
`✓` = событие реально, `✗` = ложное срабатывание, любой другой тип = переразметка.

После добавления файла — `git commit && git push`, затем `python3 ../build/score_agents.py`
пересчитает score по всем разметкам в этой папке.
